# The Quasar SMP Website

This is the full website code for the Quasar SMP. Basically, it just asks this [specific plugin](https://www.example.com) for a bunch of data on the serve and displays it if logged in. thats about it for now.

## Project Structure
To start the website run `server.js` and it should run. Most stylistic customizations can me made in `/public/css/base/variables.css` and 
`/public/css/base/typography.css`. If you need to change logos update the favicon and etc. This website is meant to run off of a minecraft
plugin so you might have better luck just taking idea from this and building your own. I do not really intend for people to fork this, but if
you want to then make sure to make and environment file, and use `.env.example` for all nesccary values.
